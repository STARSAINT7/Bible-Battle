Bible Battle is an immersive, high-performance, single-file web application designed to test, challenge, and expand users' knowledge of Biblical characters and scriptures through a Computer-Based Testing (CBT) interface.

Built as part of the Back2Bible campaign, this platform combines rigorous scriptural education with modern web design inspired by professional academic quiz systems.

🚀 Key Features
200 "Who Am I?" Questions: Comprehensive coverage spanning both the Old and New Testaments, divided into two distinct progressive stages.

Features authentic pre-exam name registration, stage selection, smooth question navigation, live timers/streaks, and professional confirmation dialog modals.

Instant Scripture Feedback: Immediate correct/incorrect response banners loaded with precise book, chapter, and verse references for deeper study.

Dynamic Glassmorphism UI: Built with Tailwind CSS, FontAwesome icons, animated multi-color gradients, and responsive card layouts optimized for both mobile and desktop screens.

Single-File Architecture: Pure HTML5, Tailwind CSS, and Vanilla JavaScript—fully self-contained, lightweight, and ready for instant offline usage or zero-config hosting (e.g., GitHub Pages).
